# Audio demos

Rendered by the firmware's own audio code on a computer (`tools/render`, the same DSP as on the FM-1), during
development; 16-bit mono, 44.1 kHz. Not recorded from a real FM-1.

| File | What |
|---|---|
| `01_tanpura_Pa_SaA2_jawari50.wav` | the tanpura: first string Pa, Sa A2, jawari 50 (step 2b, the version in the firmware) |
| `02_teentaal_160_with_tanpura.wav` | tanpura, then Teentaal at 160 matras a minute |
| `03_ektaal_120.wav` | Ektaal at 120 |
| `04_jhaptaal_140.wav` | Jhaptaal at 140 |
| `05_teentaal_drut_480.wav` | Teentaal drut, 480 |

Tabla recordings: Freesound pack "tabla bols" by mmiron (CC0).
